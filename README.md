# Лицей «Набережная» / Embankment Lyceum

Учебный портал школы-лицея: расписание, материалы, сдача работ, тесты и журнал. Это макет для портфолио на Next.js, не действующее учреждение и не витрина курсов.

Интерфейс на русском и английском — два отдельных текста, не подстрочник.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Корень перенаправляет на `/ru`. Английский: `/en`.

## Демо-вход

Пароль у трёх ролей: `demo`

| Роль | Почта |
| --- | --- |
| Ученица 11-Б / student, Form 11-B | `student@embankment.local` |
| Преподаватель информатики / informatics teacher | `teacher@embankment.local` |
| Учебная часть / office | `admin@embankment.local` |

После входа открывается кабинет роли. Состояние демо (сдачи, оценки, объявления) хранится в `localStorage` браузера. Сброс — в настройках администратора.

## Контур, который стоит пройти

1. Ученица: сегодня → урок информатики → сдача `even_sum` → тест по спискам → журнал.
2. Преподаватель: проверка сдач → оценка или возврат → журнал группы.
3. Администратор: люди, группы, зачисление, объявление.

## Стек

Next.js 15 (App Router), React 19, TypeScript. Без отдельного бэкенда: данные и вход живут на клиенте, чтобы рекрутер мог кликать без сервера.
